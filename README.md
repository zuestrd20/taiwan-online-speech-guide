# 台灣網路言論自助指南

繁體中文、靜態、適合一般讀者的法律與程序學習網站。這不是官方網站，不提供個案法律意見，不保證勝訴或可免律師。

## 使用方式

- 先閱讀三件事與程序步驟，再參考去識別案例及官方原文。
- 文件範本為原創通用教學文件，不是官方核可表格。DOCX 可編輯，PDF 供閱讀預覽。
- 下载後在自己的裝置填寫。請勿將姓名、地址、證據或案情提交到此公開專案。
- 證據勾選只留在目前頁面記憶體，重整會清除；網站不收集使用者個案資料，不使用分析追蹤、Cookie 或 localStorage。GitHub Pages 等主機服務仍可能記錄連線資訊。
- 緊急人身危險請先求助 110，緊急救護請撥 119。

## 內容與來源

查核：2026-10-04 UTC（台灣時間 2026-10-05）。法律、期限與程序可能更新；每次送件前請核對官方資料。

`data/content.json` 是供下載的公開內容、案例與來源；`data/content.js` 是同份資料的網站載入版本。各項法律敘述與案例旁提供來源連結。案例是教學摘要，不代表相同用語必有相同結果。

修訂原則：保持來源可追溯、保留審級及確定性，不用辱詞清單或勝訴評分取代法律判斷，不建立自動期限計算器。改變內容時，同步更新 JSON / JS、查核日期及資源版本。

## 本機閱讀與測試

無建置工具或後端。以任意靜態 HTTP 伺服器提供根目錄即可，例如 Python 3：`python -m http.server 8080`，然後開啟 `http://localhost:8080`。

資料與檔案檢核：`python tests/validate.py`。
互動測試：安裝 Playwright 後，以 `node tests/ui.cjs http://localhost:8080` 執行。測試不會向網站提交使用者資料。
